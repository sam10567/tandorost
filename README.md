# تندرست | Tandorost

پروژه‌ی آموزشی پلتفرم معرفی پزشک و رزرو آزمایشی نوبت با Next.js App Router، React، TypeScript و Tailwind CSS.

## اجرا
1. این پوشه را در VS Code باز کنید.
2. در ترمینال اجرا کنید: `npm.cmd install`
3. سپس: `npm.cmd run dev`
4. مرورگر: http://localhost:3000

## تصویرها
تصویرهای محلی در `public/images/` قرار می‌گیرند. فایل `doctor-hero.svg` یک تصویر جایگزین ساده است؛ برای تطبیق با مرجع، تصویر آماده‌ی خودتان را با نام `doctor-hero.jpg` یا `doctor-hero.png` در همین پوشه قرار دهید و مسیر `src` را در `components/Hero.tsx` عوض کنید.
تصویرهای پزشکان در این نسخه از Unsplash Source URL استفاده نمی‌کنند؛ از SVGهای محلی استفاده شده تا پروژه بدون وابستگی به سرویس خارجی اجرا شود.

## توجه
این نسخه فرانت‌اند آموزشی است. ورود، رزرو و نوبت‌ها آزمایشی‌اند و هنوز به سرور یا پایگاه داده وصل نیستند.
